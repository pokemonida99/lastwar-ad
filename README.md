# 末日小隊（暫名）

Last War 廣告裡那個小遊戲的玩法原型：小隊沿街往前衝，左右拖曳選門加人、閃開尖刺和坑洞、自動開槍掃殭屍群，最後打 Boss。人物和介面先照廣告模仿，設定之後再改。

![殭屍群](design/v0.1_殭屍群.jpg) ![Boss](design/v0.1_Boss.jpg)

## 本機跑

```bash
python3 -m http.server 4490 --directory lastwar-ad
```

打開 http://localhost:4490 ，手機直式最順，電腦可用方向鍵。

## 改設定

- **名稱、數值、關卡**：只改 `js/data.js`。分小學、國中、高中三個版本，各 5 關，用 `level('第 1 關', 起始人數, Boss 血量, [ ...每一列 ])` 寫：
  - `['左門', '右門']` 整排兩個門；`['單門']` 單一門，另一邊自動放尖刺或坑洞
  - `{ horde: 30 }` 殭屍群；`{ spikes: 0 }`、`{ holes: 3 }` 在 x 位置放陷阱
- **門的算式**（`js/calc.js`）：開頭 `+`／`×` 是藍門、`−`／`÷` 是紅門，但實際加減看算出來的數字，所以藍門可以倒扣（`+ 3×4−20` 其實 −8）、紅門可以反加（`− (−10)` 其實 +10）。可以用 `+ − × ÷`、括號、負號、`√`、次方（`²` `³` 或 `^`）、階乘 `!`、`log₂` `log₃` `log₁₀`、`C(n,k)`、`P(n,k)`。過門時頭上跳出實際加減多少。長算式會自動拆兩行。
- **人物外型**：`js/main.js` 的 `soldierGeo`（小兵）、`heroGeo`（隊長）、`zombieGeo`（殭屍／Boss）都是程式拼出來的方塊公仔，顏色直接改色碼。
- 測試用：網址加 `?fast=4` 會快轉；主控台可以用 `__game.step(n)` 直接推進 n 格（分頁在背景時也能跑）。
- 驗算全部門的算式：`node` 載入 `js/data.js` 和 `js/calc.js`，對每個門呼叫 `parseGate(…).apply(人數)`。

## 玩法細節

- 小學：加減乘除、括號、先乘除後加減。國中：負數、次方、開根號。高中：指數、對數、階乘、排列組合。每個版本越後面算式越長，後面幾關會出現倒扣的藍門、反加的紅門，還有兩個紅門二選一（看哪個扣得少）。三個版本一開始都能選，版本內照順序解鎖。

- 每個小兵各自判定陷阱，隊伍越大越難完全閃開，邊邊的人會被削掉；有人倒下後停 0.6 秒才補位，壓在陷阱上時不補位、不減速。
- 殭屍群進到 15 公尺內會衝過來，貼上後一換一。開槍距離 16 公尺，射速 = 人數 × `fireRate`。
- Boss 貼身時每秒踩死 `bossHitRate` 個，每死一個給 Boss `bossContactDamage` 傷害，所以人多就硬推得過去。子彈打 Boss 傷害較高、Boss 會直接衝過來，Boss 戰約 4 秒。
- 沒有儲值、登入獎勵、等待時間；三關照順序解鎖，存在瀏覽器裡。
